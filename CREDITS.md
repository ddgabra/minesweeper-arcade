# Credits

Highway Run uses work by these artists. Vehicle names identify the models; this project has no manufacturer affiliation. Driving specifications are approximate gameplay tuning, not manufacturer data.

## Car models

All models were converted for the game: extracted from showcase scenes, rescaled to real-world length, reoriented, simplified, compressed, given new paint, and rigged so the wheels spin and steer. Traffic versions are further simplified with texture colours baked into the materials.

## Textures

Asphalt, grass, red sand, snow and concrete textures are from [Poly Haven](https://polyhaven.com) under [CC0](https://polyhaven.com/license): `asphalt_02`, `aerial_grass_rock`, `red_sand`, `snow_02`, `concrete_floor_02` (converted to WebP).

## Software

[three.js](https://threejs.org) (MIT), Draco decoder (Apache 2.0), [glTF Transform](https://gltf-transform.dev) and [meshoptimizer](https://github.com/zeux/meshoptimizer) (MIT) for the model pipeline.
